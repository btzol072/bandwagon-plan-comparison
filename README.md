## 搬瓦工常見問題

**哪個方案速度最快？**
單看速度和延遲，香港、東京 CN2 GIA 最快，大阪緊隨其後；考慮到價格，CN2 GIA-E 切到日本軟銀機房是速度與價格之間的平衡點。

**買錯了能退款嗎？**
新註冊帳戶 30 天內可申請退款，超過期限就不支持了。拿到機器先測速，再決定留不留。

**支援支付寶嗎？**
支援支付寶、微信支付、PayPal 和信用卡，不需要找代購。

**能裝 Windows 嗎？**
不支援直接安裝 Windows，需要圖形介面的話可以透過 VNC 安裝 Linux 桌面環境。

**IP 被封了怎麼辦？**
規範使用是前提。IP 因違規被封後，該機器無法再切換機房，只能申請新 IP 或另購機器。

**想要的方案缺貨怎麼辦？**
低價方案和 CN2 GIA 直連方案常年缺貨，要麼蹲補貨，要麼直接上長期有貨的 CN2 GIA-E；之後可以在後台補差價升級到更高配置。
